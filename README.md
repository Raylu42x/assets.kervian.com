# assets.kervian.com

Static asset hosting for the Kervian network. Images and videos stored here are served via Cloudflare CDN and referenced by other Kervian sites.

## Structure

```
img/      # Images used across kervian.com network
videos/   # Videos used across kervian.com network
```

Assets are served from `assets.kervian.com` and linked by the other sites directly.
